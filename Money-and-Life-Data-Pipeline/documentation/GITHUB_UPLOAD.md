# Upload to GitHub Desktop

1. Open GitHub Desktop.
2. Choose **File → Add Local Repository** and select this project folder.
3. If it says this is not a Git repository, choose **Create a Repository Here**.
4. Check the changed files. Your original data and `.venv` should **not** appear.
5. Write a short commit message and click **Commit to main**.
6. Click **Publish repository**. Start with a private repository if you prefer.

Do not upload raw data or private files without checking what is inside them.
